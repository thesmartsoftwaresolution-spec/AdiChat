## 2. Public and authentication flows

### Welcome / Landing

-   Create account → Sign Up.
-   Log in → Login.
-   About the developer → Developer Intro.
-   Theme switch → persist selected Light/Dark/System preference locally
    and, when signed in, sync preference to profile settings.

### Sign Up

1.  Enter full name, email, password and confirm password.
2.  Validate required fields, email format, password requirements and
    confirmation.
3.  Submit to Supabase Auth sign-up.
4.  If email verification is enabled, show a check-inbox state and wait
    for confirmation.
5.  On verified/signed-in success, create/read the profile record and
    route to Chats List (Home).
6.  Duplicate email, weak password, network failure and rate-limit
    errors show actionable messages.

### Login

1.  Enter email and password.
2.  Supabase Auth sign-in.
3.  Load profile/status and role.
4.  If active, route to Chats List.
5.  If suspended/banned, deny protected access and show a safe status
    message.
6.  Invalid credentials show a generic error that does not reveal
    whether an email exists.
7.  Forgot Password → Forgot Password.

### Forgot / Reset Password

-   Submit email to Supabase reset-password flow.
-   Always show a neutral "Check your inbox" response to avoid account
    enumeration.
-   Email link opens Reset Password with valid recovery session.
-   Validate new password and confirmation; update password through
    Supabase Auth.
-   Success → Login.

## 3. Main user navigation

Mobile primary navigation: Chats, Assistants, Settings. New Chat action
is available from Chats List. Full-screen conversation routes use back
navigation.

Desktop: left icon rail, chat list column, active conversation pane and
optional right-side info panel, matching the Stitch design.

### Direct chat flow

Chats List → New Chat / Find Users → select a person → create/open
canonical direct conversation → Chat Conversation (1-to-1).\
Conversation header → Contact Info.\
Attachment/mic → Attachment Picker & Voice Note overlay.\
Media item → Media Viewer.\
"See all" → Shared Media & Files.\
Search icon → Global Search.

### Group flow

Chats List / New Chat → New Group - Select Members → New Group - Group
Details → create group → Group Chat Conversation.\
Conversation header → Group Info & Members.\
Add members → Add Members to Group → save → return to Group
Info/Conversation.\
Group Info → Add Assistant to Group → choose assistants and response
modes → Save.

### AI Assistant flow

Assistants tab → AI Assistants Hub.\
Create → Create AI Assistant → save → Hub.\
Assistant card → AI Assistant Profile & Settings.\
Open chat → AI Chat Conversation.\
Group Info → Add Assistant to Group.\
AI message send → authenticated Cloudflare Worker endpoint → Workers AI
→ response → persist and stream/display.

### Super Admin bootstrap

1.  Adeel Bhatti creates a normal account through Sign Up.
2.  An operator verifies the exact account identity (preferably the
    confirmed Auth user UUID and verified email; never rely on display
    name alone).
3.  A one-time trusted bootstrap operation grants the Super Admin role
    to that existing Auth user.
4.  The bootstrap operation is disabled or made unusable immediately
    after successful execution.
5.  Verify admin access and audit event.
6.  No public registration field, client-side request or ordinary admin
    endpoint can grant Super Admin.
7.  Store the bootstrap evidence/operation result securely; do not
    include bootstrap secrets in source control.

## 7. Navigation and data integrity rules

-   Use canonical conversation IDs; do not derive IDs from untrusted
    client strings.
-   Route params must be validated and access checked before rendering
    data.
-   Preserve return path after login only if the target route is
    authorized.
-   After logout, clear cached private data and subscriptions.
-   When membership is revoked, immediately remove access and stop
    realtime subscriptions.
-   Use optimistic message UI only with reconciliation and retry
    handling.
-   Use cursor pagination for message history and large admin tables.
